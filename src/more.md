## Keeping it simple

I think that browser technology is extremely capable these days, and I love the possibilities it offers for interactive apps such as games and document editors, but I do think that many websites these days are overengineered and bloated.

To practice what I preach, I built this website using some simple frameworks which convert everything to HTML and CSS files resulting in a static site which will load fast and run even if you have JavaScript disabled.

I always aim to start with the most straightforward implementation and work from there, adding complexity only when it's needed to achieve the project's goal.

## AI

I think most of the criticisms towards the recent developments in generative AI are very valid, however at the current performance and price point it's hard to ignore its usefulness as a tool for software development. It has enabled me and many others to supercharge our code output and debugging abilities.

I draw the line at replacing human expression though and strongly oppose the use of genAI in the arts. All my game art is hand drawn and the text on this website and my other projects is human written. I guarantee that any response you receive from me will be written in my own words, and I ask the same of you!

I am willing to take on 100% AI free work or discuss the degree of AI involvement you expect from a job.

The software "90/90 rule" is more relevant than ever: 

> The first 90 percent of the code accounts for the first 90 percent of the development time. The remaining 10 percent of the code accounts for the other 90 percent of the development time.
> — Tom Cargill, Bell Labs

In my experience, for creating fast prototypes, or for cranking out most of the initial implementation, AI can be extremely effective, but actually pushing a project over the finish line is still just as hard, maybe even harder as we've had less involvement in creating the base which we're building upon.
