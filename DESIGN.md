# Sebastian Boutin Blomfield personal site design

## Overview
- The site itself is open-sourced as part of the portfolio
- The finished result is a static website, uploadable to a "classic" web host without needing to build any server functionality
- Adding new portfolio entries and editing the content in general is easy, probably using markdown
- The process of how I built the site should be documented to show how I work and what my thought process is
- No overengineering, keep it all simple

## Process

- Just make commits for each step and make the message sufficiently descriptive for now.
- Start thinking about a cool way to step through the commits showing the project's progression.

## Tech stack

- Lit web components, web components are native JavaScript and Lit is a very light layer on top of that.
- Bun to compile the frontend and run a dev server to view the project locally. (no prod server needed as it runs on a static web host).
